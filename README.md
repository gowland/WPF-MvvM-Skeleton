# WPF-MvvM-Skeleton
Model-View-ViewModel Skeleton Project

## Requirements
- .NET 10 SDK (Windows, WPF)
- Build and run: `dotnet run --project MvvM\MvvM\MvvM.csproj`

## Projects
- `MvvM` – classic MVVM sample (`ICommand` + `INotifyPropertyChanged`) built on `MvvMCore`
- `MvvMReactive` – same customer demo using ReactiveUI and DynamicData (`dotnet run --project MvvM\MvvMReactive\MvvMReactive.csproj`)
- `DotNetCore` – general-purpose extension methods
